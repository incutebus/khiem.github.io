What Is CI/CD?

CI/CD stands for Continuous Integration and Continuous Delivery. Every time a developer pushes code, a pipeline builds it, tests it, and can release it automatically.

Securing the Pipeline

Adding security checks to the pipeline means problems are caught automatically before code reaches production.

Before Deployment

  • Scan the code for bugs
  • Check libraries for known issues
  • Look for passwords left in code

During Deployment

  • Require approval to release
  • Store credentials as secrets
  • Limit what the pipeline can access

Common Tools

GitHub Actions and Azure DevOps are two popular tools for building pipelines. Security scanners can be added to either one as extra steps.
