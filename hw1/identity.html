Identity and Access Management

Identity and Access Management (IAM) decides who can use an application or cloud resource and what they can do with it.

Authentication vs. Authorization

Authentication checks who you are, for example with a password and a code from your phone. Authorization checks what you are allowed to do after you sign in.

Common Security Controls

  • Multi-factor authentication (MFA)
  • Role-based access control (RBAC)
  • Least privilege: only give the access that is needed

Managed Identities and Secrets

Applications need identities too. In Azure, a managed identity lets a resource sign in to other services without a password stored in the code. Other secrets, like API keys, should be kept in a service such as Azure Key Vault.
