Identity and Access Management

Identity and Access Management (IAM) controls who can access applications and cloud resources. It helps protect sensitive systems and information.

Authentication vs Authorization

Authentication verifies who someone is. Authorization determines what that person is allowed to access.

Common Security Controls

  • Multi-factor authentication (MFA)
  • Role-based access control (RBAC)
  • Least privilege permissions
  • Secure credential management

Service Principals and Managed Identities

Applications also need identities to access cloud services. In Azure, service principals and managed identities can be used for application authentication.

Managed identities allow supported Azure resources to authenticate without developers managing passwords or client secrets.

Secrets Management

Passwords, API keys, and connection strings should not be placed directly in source code. Services such as Azure Key Vault help manage sensitive credentials.
