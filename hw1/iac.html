What Is Infrastructure as Code?

Infrastructure as Code (IaC) means setting up servers, networks, and storage by writing configuration files instead of clicking through a website. The files can be saved, reviewed, and reused like any other code.

Terraform

Terraform is a common IaC tool. You describe what you want in a file, and Terraform shows a plan of the changes before it creates anything.

Policy as Code

Policy as Code uses automatic rules to check these files for unsafe settings, such as:

  • Storage that anyone on the internet can read
  • Missing encryption
  • Permissions that are too broad

Checkov

Checkov is a free tool that scans Terraform and other configuration files for problems like these. It can run in a CI/CD pipeline so issues are found before deployment.
